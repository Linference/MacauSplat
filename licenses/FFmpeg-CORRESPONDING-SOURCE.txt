How to obtain the corresponding source
--------------------------------------

1. Exact upstream source snapshot (preferred; smallest download, and the
   snapshot revision is recorded verbatim in the shipped binary's version
   string and therefore verifiable offline): the FFmpeg project distributes a
   generated source archive for every commit:

     https://github.com/FFmpeg/FFmpeg/archive/7c533d0f86f13a06ec93968f6194349665b3536a.tar.gz

   Snapshot commit:  7c533d0f86f13a06ec93968f6194349665b3536a
   Snapshot date:    2026-08-14
   Verify with:      the version string reported by the shipped binary, i.e.
                     `engines\ffmpeg\ffmpeg.exe -version` prints
                     "n8.1.2-44-g7c533d0f86-20260821", whose "-g7c533d0f86"
                     field is this commit abbreviation.

2. Official release source archive for the 8.1.2 release this snapshot is
   based on:

     https://ffmpeg.org/releases/ffmpeg-8.1.2.tar.xz
     Size:    11,710,924 bytes
     SHA-256: 464BEB5E7BF0C311E68B45AE2F04E9CC2AF88851ABB4082231742A74D97B524C

   This is the same archive and the same SHA-256 value that
   engines/manifest.macos.json pins for the macOS arm64 engine build
   (engines[0].sourceUrl / engines[0].sourceSha256). The value is therefore

How this Object Code was built
------------------------------

The Object Code was not built by Linference. It is an unmodified, redistributed
official build produced by the BtbN/FFmpeg-Builds project. The build recipe is
therefore the upstream recipe, and every file in it is publicly retrievable and
pinned by the archive hash below:

  Archive:  https://github.com/BtbN/FFmpeg-Builds/releases/download/autobuild-2026-08-21-13-40/ffmpeg-n8.1.2-44-g7c533d0f86-win64-lgpl-shared-8.1.zip
  SHA-256:  e30201900132c0e3da178c63c7dac65aa0a0dcd971779546ae964b86b47bd499

  This SHA-256 is the same value recorded in engines/manifest.json
  (engines[0].archiveSha256) and is verified by `npm run setup:engines:windows`

License scope of this build
---------------------------

The variant enables --enable-version3 and therefore builds FFmpeg under the
LGPL version 3 or later, which is a permitted "or later" option of
LGPL-2.1-or-later. This distribution declares LGPL-2.1-or-later, matching the
manifest and licenses/THIRD_PARTY_NOTICES.txt.

The build disables GPL and nonfree components. The configure line printed by
`ffmpeg.exe -buildconf` confirms this: it contains no --enable-gpl and no
--enable-nonfree, and it explicitly disables the GPL-only encoders
(--disable-libx264, --disable-libx265, --disable-libxvid, --disable-libdavs2,
--disable-libxavs2, --disable-libfdk-aac).

Relinking (LGPL v2.1 Section 6(b))
----------------------------------

The FFmpeg library is used as a shared library (DLLs shipped alongside
ffmpeg.exe and ffprobe.exe). Users may modify FFmpeg and relink it with the
application by replacing the shipped FFmpeg DLLs with their own build of the
same shared-library ABI.
