MacauSplat — Third-party notices
================================

This notice indexes the native engines and preview libraries directly
distributed with or downloaded by MacauSplat, a derivative work based on
OOOSplat (https://github.com/ooolabdev/ooosplat, Apache-2.0). Each component
remains subject to its own license.
For the macOS runtime, BUNDLED-COMPONENTS.json is generated from the dylibs
actually copied into the release and records their Homebrew formula, declared
license, homepage, and packaged files. Release verification rejects an
unmapped dylib. Windows and Linux transitive dependency auditing remains
separate from this direct component notice.
This direct component list is not represented as a complete audit of
transitive dependencies such as Qt, Boost, Ceres, or their dependencies.

Note on the LGPL FFmpeg build: because the LGPL FFmpeg and FFprobe executables
and their shared libraries ship without the corresponding source code, the
written offer required by LGPL-2.1 Section 6 is a separate document,
licenses/FFmpeg-CORRESPONDING-SOURCE.txt, and it is packaged into every
platform bundle alongside this file.

This product distributes the LGPL FFmpeg and FFprobe executables and their
shared libraries without the corresponding source code, so that file carries the
written offer required by LGPL-2.1 Section 6. It records the exact source
snapshot (commit 7c533d0f86f13a06ec93968f6194349665b3536a, the revision named in
the shipped binary's own version string), the release source archive URL and its
SHA-256, the upstream build recipe files, and the relinking option. The file is
listed in every platform's Tauri bundle resources, so it ships inside the
installer rather than only in this repository. A link to ffmpeg.org alone would
not discharge that obligation.

macOS 15+ Apple Silicon arm64 distribution: FFmpeg and FFprobe 8.1.2 shared
executables built by this project (Linference, the publisher of MacauSplat), not
by upstream OOOSplat. The build uses the unmodified release source archive
https://ffmpeg.org/releases/ffmpeg-8.1.2.tar.xz, disables GPL and nonfree
components, and is packaged with its required shared libraries. The source
archive URL, its SHA-256, and the build policy are recorded in
engines/manifest.macos.json. Homebrew is not a runtime dependency.

How the macOS runtime is obtained (this is what the implementation actually
does, and what engines/manifest.macos.json declares): the runtime binary archive
is built and published by this project, from the pinned sources above, by
.github/workflows/macos-engines.yml under the tag recorded in
engines/manifest.macos.json (distribution.tag, prefix
engines-macos-arm64-v), and verified against the SHA-256 published beside it.
scripts/setup-engines-macos.sh downloads that archive, checks its SHA-256, and
extracts it. If the archive is not available, the script falls back to
scripts/build-engines-macos.sh, which rebuilds the runtime from the pinned
sources on the same terms. No macOS engine binary is downloaded from the
upstream OOOSplat release page: upstream publishes no engines-macos-arm64-v*
tag, so any manifest or notice claiming that provenance would be false.

The selected shared build disables GPL and nonfree components. The complete
configure string can be inspected with `ffmpeg.exe -buildconf`; the exact string
for the Windows build is recorded in licenses/FFmpeg-CORRESPONDING-SOURCE.txt.
